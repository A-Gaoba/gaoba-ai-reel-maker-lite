# GAOBA AI Reel Maker Lite

This folder makes short animated reels (MP4). The user is a beginner, not a programmer: reply in their language
(Arabic by default) and run the commands yourself.

For any of these, read `.claude/skills/reel-maker-lite/SKILL.md` first and follow it:
- "افحص جهازي" / check my setup → section A
- "سوّي ريل عن …" / make a reel or video about a topic → section B
- a change to a reel that was made → section C
- "سجّلت صوتي" / the user recorded their own voice for a reel → section D

Never claim a video exists unless the export command printed its path and the file is there.
